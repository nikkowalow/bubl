
# Bubl

![Alt text](/src/images/bublLogo.png?raw=true "Bubl")

Bubl is a decentralized event hosting and ticketing protocol built on the Solana blockchain

## Getting Started

```
$ git clone https://github.com/nikkowalow/bubl.git
$ cd bubl
$ npm i
$ npm start
```
Open [http://localhost:3000](http://localhost:3000) to view the app in the browser of your choice

## What exactly is Bubl?

Bubl is a decentralized event hosting and ticket protocol.
It allows people to easily host a private event or “bubble” (hence the name Bubl).

Customers can then later buy tickets (SPL-tokens) using SOL. 

## What kind of events can you host and attend?

Some very simple examples are: 
* Concerts
* Sports events
* Restaurant reservations
* Wine tastings 
* Reading clubs
* Music Festivals

But in reality, you can host and attend almost anything. Bubl is a very flexible platform and has the ability to host a magnitude of different events. Whether it be a few person private dinner or a sports event with tens of thousands of people attending, Bubl has you covered. 

## Roadmap and Future Plans

* “Event of the Day” feature where a user can pay extra SOL to promote their event to the front page of the website
